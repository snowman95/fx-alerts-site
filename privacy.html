대상: 독립 iPhone 앱 ‘환율 급등급락 알리미’ 및 이 안내 사이트
게시 기준일: 2026년 10월 7일 · 운영자: Jihoon Han

ECB 일별 서버 전환과 기존 기기 인증 상태 보존을 확인했습니다. 대응 앱 버전과 실제 iPhone 수신 검증은 준비 중입니다. 아래 알림 서버 처리는 사용자가 알림 설정·기기 연결을 요청할 때 적용됩니다. 공개 HTTPS 요청은 Cloudflare를 경유합니다.

1. 이용 방식

회원가입·계정 로그인과 앱 내 구매, 별도의 자체 행동 분석 SDK를 사용하지 않습니다. 현재 내부 TestFlight 빌드는 Google 테스트 광고를 사용하며 운영 광고와 새 ECB 대응 버전은 준비 중입니다. 광고 SDK 정보 처리는 아래 별도 항목에서 안내합니다. 토스 계정·구매·알림 구독을 가져오지 않습니다. 앱을 열람하는 것만으로 이름·이메일·전화번호를 요구하지 않습니다.

2. iPhone에 보관되는 값

선택 통화·마지막 확인한 ECB 공개 환율 자료·추가 비교 카드는 앱 저장소에 보관합니다. 환산 입력은 화면의 기기 메모리에서 계산하며 운영자 환율 수집·알림 API나 광고 요청에 넣지 않습니다. 서버 설정을 관리하기 위한 무작위 설치 인증 비밀값도 이 기기에 보관합니다. 원본 비밀값은 인증 요청 시 HTTPS로 전달되지만 서버의 영구 저장소에는 원본을 보관하지 않고 해시값으로 설치를 구분합니다. 앱 삭제·저장소 초기화 시 이 값이 사라질 수 있으며, 이전 서버 기록과 다시 연결된다는 보장은 없습니다.

이 데이터는 운영자의 PC에서 별도 iOS 알림 서비스 저장소에 보관합니다. 원본 설치 비밀값·확인 코드는 저장용 해시와 구분됩니다. 확인 코드는 실제 푸시 발송과 입력 검증 과정에서 일시적으로 처리합니다.

네트워크 요청은 연결 과정에서 IP 등 통신 정보를 노출할 수 있습니다. API의 요청 제한 카운터는 서버 메모리에서 처리합니다. 공개 HTTPS 연결을 제공하는 Cloudflare는 요청을 프록시 처리하면서 IP 주소, 요청 시각, HTTP 헤더 등 통신 메타데이터와 전달되는 요청 데이터를 처리할 수 있습니다. 외부 제공자의 로그 보관기간을 앱의 구독·발송 기록 보관기간과 같다고 보장하지 않습니다.

4. 보관과 삭제

  • 서버 구독을 해제하면 해당 구독과 조건 평가 상태를 삭제하고 대기 중인 관련 알림을 차단합니다. 설치 기록·기기 토큰 전체가 함께 삭제되는 동작은 아닙니다.
  • 알림 발송 기록은 worker가 정상 실행될 때 기준시각으로부터 7일을 넘긴 항목을 정리합니다. worker가 중단되면 정리가 지연될 수 있습니다.
  • 기기 토큰 해시별 일자 단위 확인 요청 제한 기록은 worker가 정상 실행될 때 오늘·전일보다 오래된 기록을 정리합니다.
  • 확인 코드는 발급 후 5분 동안 유효하며 최대 5회 입력 시도를 제한합니다. 성공·만료 확인·새 요청 과정에서 확인 기록이 삭제되거나 교체됩니다. 만료시각이 지나는 즉시 저장 파일에서 일괄 삭제된다고 보장하지 않습니다.
  • 설치 해시·기기 연결 시각·기기 토큰·미해제 구독에는 현재 자동 만료·전체 삭제 정책이 구현되어 있지 않습니다. Apple이 토큰을 유효하지 않다고 응답하면 해당 기기의 토큰·연결 상태를 제거할 수 있으나 설치 기록 전체가 사라지는 것은 아닙니다.
  • 앱 삭제나 iPhone 알림 권한 해제는 서버 전체 데이터 삭제와 별개입니다. 데이터 관련 요청은 아래 운영자에게 문의해 주세요.

5. 외부 서비스와 시세 출처

  • Cloudflare: 앱의 공개 HTTPS 요청을 알림 서비스로 전달하는 프록시 역할입니다. 연결 과정의 IP·HTTP 메타데이터와 전달되는 요청 데이터를 처리할 수 있습니다. Cloudflare 개인정보 안내
  • Apple APNs: 기기 연결 확인과 환율 알림 발송에 사용하며, 기기 토큰과 알림 내용이 Apple에 전달됩니다.
  • ECB·Frankfurter: 서버가 ECB 일별 공표 자료를 수집하고 같은 공표일의 값을 원화로 교차 계산합니다. Frankfurter는 ECB 전용 경로만 사용하며 실패하면 공식 ECB 공개 XML을 읽습니다. 공급자 시세 요청에 APNs 토큰·설치 인증값·알림 구독·계산 입력을 넣지 않습니다.
  • 운영자 PC: 대응 앱은 공개 /rates에서 ECB 자료만 조회하며, 기기 연결·구독은 별도 인증 API를 사용합니다. 새 ECB 앱에서는 기존 Toss/Supabase 시세·Yahoo·ExchangeRate-API 자료를 읽지 않습니다. 과거 내부 빌드의 처리 방식은 새 앱과 다를 수 있습니다.
  • GitHub Pages: 이 안내 사이트와 이미지·스타일 파일을 제공합니다. 방문 연결 과정에서 IP 등 통신 정보를 처리할 수 있습니다.

시세 출처의 자료 제공·수집·API 반영에는 지연이나 누락이 생길 수 있으며, 조회·계산·알림은 같은 ECB 출처와 공표일을 기준으로 하지만 자료 수신 시점에 따라 앱·서버가 보유한 최신 날짜는 다를 수 있습니다. 무료 ECB 원자료의 출처와 원화 파생 계산을 명시하며 실시간 거래가격을 제공하지 않습니다.

이 사이트 자체에는 분석 스크립트·광고·로그인·문의 수집 폼·추적 쿠키를 넣지 않습니다. 호스팅·통신 제공자의 별도 처리는 해당 제공자의 정책에 따를 수 있습니다. 이메일 문의는 사용자가 선택한 메일 서비스와 운영자의 메일함을 통해 처리됩니다.

6. 문의와 변경 안내

정보 처리, 열람·정정·삭제 요청과 서비스 문의를 받습니다. 식별 가능한 기록 확인이 필요한 경우 추가 절차를 안내합니다. 설치 비밀값·확인 코드·기기 토큰·계정 비밀번호를 이메일에 넣지 마세요. 운영 방식이 바뀌면 이 페이지의 기준일과 내용을 갱신합니다.

환율 공유 링크

공유 버튼은 통화 코드, 일별 참고 환율과 자료 기준일을 공개 안내 페이지의 URL에 담습니다. 링크를 받은 사람이나 공유한 서비스는 이 공개 시세 값을 볼 수 있습니다. 기기 토큰, 설치 인증 비밀값과 알림 구독 정보는 링크에 담지 않습니다. 링크 페이지는 입력값을 표시하며 새 시세를 조회하지 않습니다. 공개 사이트 접속과 미리보기 이미지 요청은 GitHub Pages에서 처리합니다.

광고 SDK를 적용하는 새 iOS 버전

기존 내부 테스트 빌드와 구분하여, 새 버전에는 Google AdMob 배너와 사용자가 선택하는 보상 광고를 준비하고 있습니다. 개발용 테스트 광고 표시를 확인했으며 8개 앱의 운영 광고 단위 등록과 지역별 개인정보 메시지 게시를 마쳤습니다. 새 버전의 앱별 동작 검증과 제출 준비는 진행 중입니다. 정식 운영 광고가 이미 제공되거나 새 버전이 App Store에 공개되었다는 뜻은 아닙니다.

광고가 적용되는 버전은 Google Mobile Ads SDK를 통해 광고를 요청합니다. Google의 SDK 안내에 따르면 IP 주소를 통한 대략적인 위치, 사용 가능한 기기·앱 관련 식별자, 광고 노출·클릭·영상 상호작용, 앱 성능 및 충돌 정보 등이 광고 제공·측정·부정사용 방지와 진단을 위해 처리될 수 있습니다. 별도의 운영자 행동 분석 SDK가 없더라도 광고 SDK 자체의 측정·진단 처리는 있습니다.

준비 중인 새 버전은 사용자가 ‘광고 동의 설정’을 선택한 뒤 iOS 앱 추적 투명성(ATT) 권한을 요청하도록 구성합니다. iOS에서 추적을 허용하고 Google 동의 관리 도구(UMP)도 광고 요청을 허용한 경우에만 광고 SDK를 초기화하고 배너·보상 광고를 요청합니다. 거부·제한·미결정 상태이거나 동의 확인에 실패하면 광고를 요청하지 않으며 기본 앱 기능은 계속 무료로 사용할 수 있습니다. iOS 설정에서 이 앱의 추적 권한을 변경할 수 있으며, 다시 앱으로 돌아오면 상태를 확인하고 허용이 철회된 경우 표시 중인 배너를 제거하도록 준비합니다. UMP의 지역별 개인정보 선택과 iOS 추적 권한은 별개의 설정입니다.

광고 동의 후에도 비개인화 광고 요청과 Google의 게시자 자사 식별자 비활성화를 유지합니다. 비개인화 요청은 광고 SDK의 모든 정보 수집이나 외부 입찰 광고의 측정 처리가 없다는 뜻은 아닙니다. 광고 제공에 참여하는 Google 및 외부 광고 사업자는 기기 식별자·광고 상호작용 등의 정보를 광고 제공·측정에 사용할 수 있으며, iOS 추적 권한은 다른 회사의 자료와 연결하는 광고 측정 처리에 대한 허가도 포함합니다. 새 버전의 실제 SDK 설정과 App Store 개인정보 답변을 함께 확인해 주세요.

기기의 이름·생년월일·접종 기록, 소득·재산·계산 입력, ETF 관심·보유 목록, 환율 알림 토큰·설치 인증값·구독, 로또의 현재 좌표는 광고 타기팅이나 보상 광고의 사용자 식별값으로 보내지 않습니다. 기기에서 생성한 보상 결과·이용권 시각은 로컬 저장소에서 관리합니다. 사용자가 공유·복사를 선택하면 공유 내용과 앱 안내 링크가 본인이 선택한 대상에 전달됩니다.

광고 요청 전 Google 동의 관리 도구(UMP)로 상태를 확인하고, 지역과 설정에 따라 필요한 동의 화면을 제공합니다. 도구가 개인정보 선택 재설정을 요구하면 앱의 ‘광고 개인정보 설정’에서 해당 화면을 다시 열 수 있습니다. 광고를 불러오지 못하거나 선택 광고를 취소한 것을 완료로 취급하지 않습니다. 보상은 실제 SDK 완료 콜백이 확인된 경우에만 제공합니다.

Google이 처리하는 정보의 보관·삭제 및 설정은 Google의 정책을 따르며 앱의 로컬 기록 삭제 기간과 같다고 보장하지 않습니다. 이 안내 사이트 자체에는 광고 SDK나 운영자 분석·광고 추적 스크립트를 넣지 않습니다. 문의 시 계정 비밀번호나 기기 인증값을 보내지 마세요.
