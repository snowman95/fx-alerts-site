대상: 독립 iPhone 앱 ‘환율 급등급락 알리미’ 및 이 안내 사이트
게시 기준일: 2026년 10월 5일 · 운영자: Jihoon Han

현재 생산용 알림 연결을 준비 중입니다. 아래 알림 서버 처리는 연결 완료 후 알림 설정·기기 연결을 요청할 때 적용되는 구현 내용입니다. 실제 운영을 시작하기 전에 공개 HTTPS 연결 제공자와 운영 변경 사항을 이 페이지에 반영합니다.

1. 이용 방식

회원가입·계정 로그인, 광고, 앱 내 구매와 자체 분석 SDK를 사용하지 않습니다. 토스 계정·구매·알림 구독을 가져오지 않습니다. 앱을 열람하는 것만으로 이름·이메일·전화번호를 요구하지 않습니다.

2. iPhone에 보관되는 값

선택 통화와 목표 환율은 앱 저장소에 보관합니다. 서버 설정을 관리하기 위한 무작위 설치 인증 비밀값도 이 기기에 보관합니다. 원본 비밀값은 인증 요청 시 HTTPS로 전달되지만 서버의 영구 저장소에는 원본을 보관하지 않고 해시값으로 설치를 구분합니다. 앱 삭제·저장소 초기화 시 이 값이 사라질 수 있으며, 이전 서버 기록과 다시 연결된다는 보장은 없습니다.

3. 알림 서버에서 처리하는 정보

정보사용 목적
APNs 기기 토큰Apple 푸시 알림을 해당 기기로 전송하고 연결 상태를 확인합니다.
설치 인증 정보의 해시, 연결 시각해당 설치의 구독을 조회·변경·해제하고 다른 설치와 구분합니다.
통화, 알림 종류, 목표 환율급등락·목표 이하 도달 조건을 평가합니다.
조건 평가 상태, 알림 발송 상태·시각·시도 횟수중복 알림 방지, 재시도와 오래된 알림 차단에 사용합니다.
기기 확인 코드의 해시, 요청 식별자, 만료시각, 시도 횟수실제 알림 수신 기기의 소유 확인과 오용 방지에 사용합니다. 코드 원문은 영구 저장하지 않습니다.
기기 토큰 해시별 확인 요청 횟수·시각, 일자확인 알림의 요청 빈도를 제한합니다.

이 데이터는 운영자의 PC에서 별도 iOS 알림 서비스 저장소에 보관합니다. 원본 설치 비밀값·확인 코드는 저장용 해시와 구분됩니다. 확인 코드는 실제 푸시 발송과 입력 검증 과정에서 일시적으로 처리합니다.

네트워크 요청은 연결 과정에서 IP 등 통신 정보를 노출할 수 있습니다. API의 요청 제한 카운터는 서버 메모리에서 처리합니다. 향후 HTTPS 프록시의 별도 로그·보관 방식은 제공자가 결정된 뒤 운영 전에 추가 안내합니다.

4. 보관과 삭제

  • 서버 구독을 해제하면 해당 구독과 조건 평가 상태를 삭제하고 대기 중인 관련 알림을 차단합니다. 설치 기록·기기 토큰 전체가 함께 삭제되는 동작은 아닙니다.
  • 알림 발송 기록은 worker가 정상 실행될 때 기준시각으로부터 7일을 넘긴 항목을 정리합니다. worker가 중단되면 정리가 지연될 수 있습니다.
  • 기기 토큰 해시별 일자 단위 확인 요청 제한 기록은 worker가 정상 실행될 때 오늘·전일보다 오래된 기록을 정리합니다.
  • 확인 코드는 발급 후 5분 동안 유효하며 최대 5회 입력 시도를 제한합니다. 성공·만료 확인·새 요청 과정에서 확인 기록이 삭제되거나 교체됩니다. 만료시각이 지나는 즉시 저장 파일에서 일괄 삭제된다고 보장하지 않습니다.
  • 설치 해시·기기 연결 시각·기기 토큰·미해제 구독에는 현재 자동 만료·전체 삭제 정책이 구현되어 있지 않습니다. Apple이 토큰을 유효하지 않다고 응답하면 해당 기기의 토큰·연결 상태를 제거할 수 있으나 설치 기록 전체가 사라지는 것은 아닙니다.
  • 앱 삭제, iPhone 알림 권한 해제 또는 기기 목표값 삭제는 서버 전체 데이터 삭제와 별개입니다. 데이터 관련 요청은 아래 운영자에게 문의해 주세요.

5. 외부 서비스와 이 사이트

알림 전송에는 Apple APNs를 사용하므로 기기 토큰과 알림 내용이 Apple에 전달됩니다. 환율 제공 API와 데이터 수집 과정은 시세 조회에 사용하며, 실시간 반영을 보장하지 않습니다. 생산용 HTTPS 프록시 제공자는 아직 정해지지 않았습니다.

이 안내 사이트는 GitHub Pages에 게시되어 있습니다. 사이트 자체에는 분석 스크립트·광고·로그인·문의 수집 폼·추적 쿠키를 넣지 않습니다. 호스팅 제공자의 통신 처리는 해당 제공자의 정책에 따를 수 있습니다. 이메일 문의는 사용자가 선택한 메일 서비스와 운영자의 메일함을 통해 처리됩니다.
