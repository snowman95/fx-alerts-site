Android 앱 개인정보 처리방침

대상: Google Play의 Android 앱 ‘환율 급등급락 알리미’(com.codingfactory.fxalerts)
게시 기준일: 2026년 11월 23일 · 운영자: Jihoon Han · iPhone 앱 안내는 별도 페이지에 있습니다.

1. 이용 방식

회원가입·계정 로그인·앱 내 구매·자체 행동 분석 SDK를 사용하지 않습니다. 앱을 열람하는 것만으로 이름·이메일·전화번호를 요구하지 않습니다. 환율 조회·계산·공유와 기존 알림 해제는 무료이며, 새 급등·급락 알림 신청은 선택형 보상 광고를 끝까지 본 뒤 진행합니다.

2. 휴대폰에 보관되는 값

선택 통화, 마지막으로 확인한 참고 환율과 시각, 알림 활성화를 위해 완료한 통화별 광고 내역, 이 설치를 구분하는 무작위 설치 인증값을 앱 저장소에 보관합니다. 환산 입력은 화면에서만 계산하며 서버로 보내지 않습니다. 앱을 삭제하면 이 값들은 휴대폰에서 지워집니다.

3. 알림 서버에서 처리하는 정보

정보사용 목적
FCM 등록 토큰Google Firebase Cloud Messaging으로 이 휴대폰에 확인 코드와 환율 알림을 보내고 연결 상태를 확인합니다.
설치 인증값의 해시, 연결 시각같은 설치에서 요청한 알림 설정·해제만 처리하도록 구분합니다. 원래 인증값은 서버에 저장하지 않습니다.
알림 구독(통화·조건)과 평가 상태설정한 통화가 최근 2시간 안에 5원 이상 움직였는지 판단하고 중복 발송을 막습니다.
발송 결과 기록발송 성공·실패를 확인하고 문제를 진단합니다.
요청 IP·시각(연결 처리 과정)과도한 요청 제한과 보안을 위해 일시적으로 사용합니다.

4. 보관과 삭제

  • 앱에서 알림을 해제하면 해당 구독과 평가 상태를 삭제하고 대기 중인 관련 알림을 차단합니다.
  • 발송 기록은 기준 시각으로부터 7일이 지나면 정리합니다.
  • Google이 토큰이 더 이상 유효하지 않다고 응답하면 해당 토큰과 연결 상태를 제거합니다. 설치 해시·연결 시각은 자동 만료 정책이 없으므로, 전체 삭제를 원하면 아래 연락처로 요청해 주세요.
  • 앱 삭제나 Android 알림 권한 해제는 서버 데이터 삭제와 별개입니다.

5. 외부 서비스와 시세 출처

  • Google Firebase Cloud Messaging: 확인 코드와 환율 알림 전송에 사용하며, FCM 등록 토큰과 알림 내용이 Google에 전달됩니다. Firebase 개인정보 안내
  • Cloudflare: 앱의 HTTPS 요청을 알림 서비스로 전달하는 프록시이며 연결 과정의 IP·HTTP 정보를 처리할 수 있습니다. Cloudflare 개인정보 안내
  • 시세: 서버가 Yahoo Finance의 완료된 1분봉과 ECB 일별 공표 자료를 수집합니다. 시세 공급자 요청에 FCM 토큰·설치 인증값·구독·환산 입력을 넣지 않습니다.
  • GitHub Pages: 이 안내 사이트를 제공하며 방문 과정의 통신 정보를 처리할 수 있습니다.

6. 광고

Google Mobile Ads SDK로 하단 배너와 선택형 보상 광고를 요청합니다. 모든 광고 요청은 비맞춤 방식이며 게시자 자사 식별자를 끕니다. Google의 안내에 따라 SDK는 IP 주소를 통한 대략적인 위치, Android 광고 ID 등 기기 식별자, 광고 노출·클릭 상호작용, 앱 성능·충돌 정보를 광고 제공·측정·부정 사용 방지와 진단을 위해 처리할 수 있으며 이 정보는 Google 및 광고 제공에 참여하는 사업자와 공유될 수 있습니다. 필요한 지역에서는 Google 동의 관리 도구(UMP)로 선택을 받으며, 앱의 ‘광고 동의 설정’에서 다시 열 수 있습니다. Android 광고 ID는 설정 > 개인정보 보호 > 광고에서 재설정하거나 삭제할 수 있습니다. 환산 입력·FCM 토큰·설치 인증값·구독 정보는 광고 요청에 넣지 않습니다. Google Mobile Ads SDK 데이터 안내 · Google 개인정보처리방침
