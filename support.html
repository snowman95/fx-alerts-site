사용 방법과 고객 지원

현재 출시 준비 중입니다. 알림 서버의 공개 연결은 완료했으며 실제 iPhone의 기기 연결과 푸시 수신을 최종 검증하고 있습니다. 시세 제공처의 외부 앱 제공·파생 알림 이용 권한도 확인 중입니다. 아래 절차는 알림 연결을 지원하는 버전에서 이용할 수 있습니다. 서버가 준비되지 않았다는 안내가 표시되면 알림이 활성화된 상태가 아닙니다.

통화 선택과 알림 신청의 차이

통화를 조회하거나 선택하는 것만으로 푸시가 켜지지 않습니다. 실제 알림은 알림 설정에서 권한을 확인하고, 이 기기 연결 확인을 마친 뒤 서버가 신청을 저장해야 동작합니다.

알림을 설정하려면

  1. 달러·엔·유로 중 원하는 통화에서 알림 설정을 열고 ‘급등/급락 알림 켜기’를 누릅니다.
  2. iPhone 알림 권한을 허용합니다. 시스템 설정에서 이미 거부했다면 iPhone 설정의 해당 앱 알림 메뉴를 확인합니다.
  3. ‘인증 코드 받기’를 누르고 실제 iPhone 알림으로 받은 6자리 코드를 유효시간 안에 앱에 입력합니다.
  4. ‘코드 확인하고 알림 설정’을 누르고 앱의 서버 저장 완료 안내를 확인합니다. 이미 수신 기기가 확인되어 있으면 코드 확인을 다시 요구하지 않을 수 있습니다.

급등급락 기준은 5분 동안 표시 단위당 5원 이상이며 엔화는 100엔 기준입니다. 휴장·시세 지연·서버나 네트워크 상태로 알림이 늦거나 수신되지 않을 수 있습니다.

알림 해제와 권한 끄기

  • 특정 서버 알림 해제: 해당 통화의 알림 설정에서 ‘급등/급락 알림 해제’를 선택하고 해제 완료 안내를 확인합니다. 서버와 연결되지 않으면 해제가 완료되지 않을 수 있습니다.
  • 모든 알림 표시 중지: iPhone 설정에서 이 앱의 알림 허용을 끕니다. 화면 표시 권한을 끄는 것과 서버 구독 삭제는 다릅니다.
  • 앱 삭제·저장소 초기화: 기기 저장값과 설치 인증 정보가 사라질 수 있습니다. 서버 구독·기기 기록의 즉시 삭제를 보장하지 않으며, 초기화 후 이전 구독을 앱에서 관리하지 못할 수 있습니다.

알림이나 시세가 예상과 달라요

시세 기준일, 선택 통화, 표시 단위, 서버 저장 상태와 iPhone 알림 권한을 차례로 확인하세요. 앱의 환율은 참고 시세이며 은행 거래 가격과 다릅니다. API와 데이터 갱신은 실시간을 보장하지 않습니다.
