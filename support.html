사용 방법과 고객 지원

ECB 일별 자료에 대응하는 내부 TestFlight 1.0.0(빌드 6)을 배포했습니다. 이전 버전을 사용 중이라면 TestFlight에서 업데이트해 주세요. 아래 절차는 ECB 대응 버전에서 이용할 수 있습니다. 실제 iPhone의 알림 수신은 검증 중이며 서버 저장 완료가 실제 알림 수신을 보장하지는 않습니다. App Store 공개 출시는 준비 중입니다.

통화 선택과 알림 신청의 차이

통화를 조회하거나 선택하는 것만으로 푸시가 켜지지 않습니다. 실제 알림은 알림 설정에서 권한을 확인하고, 이 기기 연결 확인을 마친 뒤 서버가 신청을 저장해야 동작합니다.

알림을 설정하려면

  1. 달러·엔·유로 중 원하는 통화에서 알림 설정을 열고 ‘급등/급락 알림 켜기’를 누릅니다.
  2. iPhone 알림 권한을 허용합니다. 시스템 설정에서 이미 거부했다면 iPhone 설정의 해당 앱 알림 메뉴를 확인합니다.
  3. ‘인증 코드 받기’를 누르고 실제 iPhone 알림으로 받은 6자리 코드를 유효시간 안에 앱에 입력합니다.
  4. ‘코드 확인하고 알림 설정’을 누르고 앱의 서버 저장 완료 안내를 확인합니다. 이미 수신 기기가 확인되어 있으면 코드 확인을 다시 요구하지 않을 수 있습니다.

기준은 직전 서로 다른 ECB 공표일 대비 USD/EUR1단위·JPY100엔당5원 이상 상승·하락입니다. 처음 관측은 기준점으로만 저장합니다. 같은 공표일 반복·수정이나 휴일의 동일 자료로 중복 알림을 보내지 않습니다. 일별 참고 자료이며 분 단위 움직임·실시간 환전가 알림이 아닙니다. PC 중단·자료 지연·네트워크·기기 설정으로 수신이 지연되거나 실패할 수 있습니다.

알림 해제와 권한 끄기

  • 특정 서버 알림 해제: 해당 통화의 알림 설정에서 ‘급등/급락 알림 해제’를 선택하고 해제 완료 안내를 확인합니다. 서버와 연결되지 않으면 해제가 완료되지 않을 수 있습니다.
  • 모든 알림 표시 중지: iPhone 설정에서 이 앱의 알림 허용을 끕니다. 화면 표시 권한을 끄는 것과 서버 구독 삭제는 다릅니다.
  • 앱 삭제·저장소 초기화: 기기 저장값과 설치 인증 정보가 사라질 수 있습니다. 서버 구독·기기 기록의 즉시 삭제를 보장하지 않으며, 초기화 후 이전 구독을 앱에서 관리하지 못할 수 있습니다.

알림이나 시세가 예상과 달라요

ECB 공표일, 선택 통화, 표시 단위, 서버 저장 상태와 iPhone 알림 권한을 차례로 확인하세요. 앱의 환율은 참고 시세이며 은행 거래 가격과 다릅니다. API와 데이터 갱신은 실시간을 보장하지 않습니다.

환율을 공유하거나 복사하려면

환율 홈이나 알림 화면에서 ‘환율 공유’ 또는 ‘내용 복사’를 누릅니다. 선택 통화, 표시 단위, 자료 기준일과 공유한 시각(KST), 앱 안내 링크가 함께 전달됩니다. 일별 자료에는 시세 시각이 없어 공유 시각과 구분합니다. 지난 기준일이면 오늘 시세가 아니라는 안내가 표시됩니다.

공유 링크는 당시 앱에 표시한 자료의 스냅샷이며 새 시세를 자동 조회하지 않습니다. 링크 미리보기는 시세 숫자가 없는 앱 소개 이미지입니다. 수신 앱의 기능·캐시·설정에 따라 미리보기 표시가 달라질 수 있습니다.

추가 콘텐츠 이용

추가 비교 카드는 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼을 선택해도 같은 콘텐츠가 제공되며, 그 광고 경로는 실제 SDK 완료 확인 후에만 저장합니다. 광고 취소·실패를 완료로 취급하지 않으며 무료 생성 경로는 계속 이용할 수 있습니다.

빌드 8의 광고·알림 활성화 안내

다음 업데이트인 빌드 8에 적용되는 안내입니다. 현재 배포된 빌드 6의 동작은 위에서 확인해 주세요. 새 버전은 시청 완료 후 급등락 알림을 신청하며, 광고 동의·라이선스 안내는 한 줄 메뉴에서 열 수 있습니다.

추적 허용과 광고 시청은 별개입니다. 추적을 거부해도 별도 광고 개인정보 선택이 허용하면 비맞춤 배너·보상 광고가 표시될 수 있습니다. 미선택·동의 확인 실패·연결 오류 등으로 광고를 이용할 수 없을 때는 기본 조회·계산·기존 기록과 알림 해제를 계속 사용할 수 있습니다.

빌드 8에서 새 알림을 신청하려면

  1. 달러·엔·유로 중 통화를 선택하고 알림 설정을 엽니다.
  2. ‘광고 시청 후 급등/급락 알림 켜기’를 선택하고 광고를 완료합니다. 혜택은 선택 통화의 알림 활성화 1회이며, 중간에 닫거나 광고를 준비하지 못하면 신청하지 않습니다.
  3. 완료 확인 후 iPhone 알림 권한과 수신 기기를 확인합니다. 필요한 경우 알림으로 받은 6자리 코드를 입력합니다.
  4. 서버 저장 완료 안내를 확인합니다. 권한·기기 확인·저장이 실패하면 완료 내역을 기기에 보관하므로 같은 통화는 광고를 다시 보지 않고 재시도할 수 있습니다. 저장이 확인되면 해당 완료 내역을 사용합니다.

기본 환율 조회·추이·계산·공유와 기존 알림 조회·해제는 광고를 보지 않아도 가능합니다. 이 버전의 보상은 선택 통화의 새 알림 활성화 1회입니다.
