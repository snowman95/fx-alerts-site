사용 방법과 고객 지원

현재 App Store 버전 1.0.0(빌드 11)을 제공합니다. 최근 5분 변동을 화면에서도 확인하는 1.0.1(빌드 12)을 TestFlight에서 제공합니다. 새 1.0.1의 정식 App Store 심사는 아직 제출하지 않았습니다. 알림 서버는 2026년 10월 12일부터 분봉 기준으로 전환되어 기존 구독에도 적용됩니다. 1.0.0의 일별 환율 화면과 새로운 알림 기준은 다르며 새 알림 신청은 업데이트가 필요합니다. 기존 구독 조회·무료 해제는 유지합니다. 실제 iPhone의 시장 알림 수신이나 모든 기기의 광고 표시를 보장하지 않습니다.

통화 선택과 알림 신청의 차이

통화를 조회하거나 선택하는 것만으로 푸시가 켜지지 않습니다. 새 알림은 선택 통화의 활성화 광고 완료와 종료를 확인한 뒤, iPhone 알림 권한·수신 기기 확인·정확히 같은 통화의 서버 구독 저장이 차례로 필요합니다. 추적 허용을 보상의 조건으로 요구하지 않습니다.

알림을 설정하려면

  1. 달러·엔·유로 중 원하는 통화를 선택하고 알림 설정을 엽니다.
  2. 혜택이 선택 통화의 급등/급락 알림 활성화 1회임을 확인하고 ‘광고 시청 후 … 급등/급락 알림 켜기’를 누릅니다. 긴 전면 광고가 표시될 수 있으며 길이와 닫는 단계는 광고마다 다릅니다.
  3. 실제 SDK 보상 완료와 광고 종료 결과를 모두 확인해야 해당 통화의 완료 내역을 기기에 저장합니다. 완료 전에 닫거나 광고가 실패하면 새 알림 신청·알림 권한·기기 확인을 시작하지 않습니다.
  4. 완료 내역 저장을 읽어 확인한 뒤 iPhone 알림 권한을 확인하고 APNs 수신 기기를 등록합니다. 이미 알림 권한을 거부했다면 iPhone 설정의 해당 앱 알림 메뉴를 확인합니다.
  5. 수신 기기 확인이 필요하면 ‘인증 코드 받기’를 누르고 실제 iPhone 알림으로 받은 6자리 코드를 유효시간 안에 입력합니다. ‘코드 확인하고 알림 설정’에서 기기를 확인합니다. 이미 확인된 기기는 코드 확인을 다시 요구하지 않을 수 있습니다.
  6. 서버에서 같은 통화의 급등/급락 구독이 저장된 것을 확인한 뒤 완료 안내를 표시합니다. 이 저장 확인 후에만 해당 통화의 광고 완료 내역을 사용 처리합니다.

권한·기기 확인·서버 저장이 실패하면 같은 통화의 광고 완료 내역으로 다시 시도하며 광고를 다시 보지 않습니다. 완료 내역을 기기에 정상 저장하고 읽어 확인한 경우 앱을 다시 열어도 재시도할 수 있습니다. 기기 저장 공간 문제로 완료 내역 보관에 실패하면 성공으로 안내하지 않습니다. 이 경우 앱을 닫지 말고 현재 앱에서 광고 없이 다시 시도해 주세요. 기존 알림 조회·해제는 광고를 보지 않아도 가능합니다.

현재 서버의 기준은 USD/EUR1단위·JPY100엔당 최근5분5원 이상 상승·하락입니다. 상세 판정과 알림 제한은 아래에서 확인해 주세요. 현재1.0.0은 새 서버 기준을 확인하지 못하면 신규 알림 신청을 중단하며, 기존 구독 조회와 무료 해제는 유지합니다. 분봉 조회·새 신청에 대응하는1.0.1(빌드 12)을 TestFlight에서 제공합니다.

광고와 추적 설정

회원가입·앱 내 구매·자체 행동 분석 SDK는 없습니다. 추적 허용 여부와 별개로, 권한 선택을 마치고 별도 광고 개인정보 설정 상태가 요청을 허용하면 비맞춤 배너·선택형 보상 광고가 표시될 수 있습니다. 기본 환율 조회·추이·계산·공유와 복사, 기존 알림 조회·해제는 계속 이용할 수 있습니다. 하단 광고 동의 설정과 홈의 오픈소스 라이선스는 한 줄 메뉴에서 눌렀을 때 열립니다.

이 버전은 앱이 처음 활성 상태가 되었을 때 추적 권한이 미결정이면 표준 iOS 앱 추적 투명성(ATT) 선택 화면을 바로 엽니다. 별도의 광고 정보 안내창이나 ‘계속’ 단계는 없습니다. 비활성 상태에서는 요청하지 않으며 이미 허용·거절·제한 상태이면 다시 요청하지 않습니다. 요청이 완료되지 않아 미결정 상태가 남아도 같은 실행 중 자동으로 반복하지 않습니다. 필요하면 ‘광고 동의 설정’에서 직접 다시 확인할 수 있습니다.

OS 선택 결과를 확인한 뒤 별도 Google 동의 관리 도구(UMP)가 광고 요청을 허용하고 앱이 활성 상태일 때만 광고를 요청합니다. 허용·거절·제한 중 어느 상태이든 현재 광고 요청은 비맞춤 방식이며 게시자 자사 식별자 비활성화를 유지합니다. 추적 허용은 기본 기능이나 광고 추가 혜택의 조건이 아닙니다. UMP의 지역별 개인정보 선택과 iPhone 알림 권한은 각각 별도입니다.

하단 배너는 본문·메뉴와 구분된 영역을 사용합니다. 화면 준비가 늦는 경우의 자동 복구는 제한된 횟수로 시도하며 무한 반복하지 않습니다. 화면 오류가 이미 결정된 동의 상태를 지우는 것은 아닙니다. ‘광고 동의 설정’을 사용자가 열었을 때만 짧은 광고 상태와 접힌 진단 정보가 보입니다. 진단에는 계정·광고 단위 ID, 설치 인증값, 기기 토큰, 확인 코드나 환산 입력을 표시하지 않습니다. 동의·라이선스 시트는 닫거나 긴 내용을 스크롤할 수 있습니다. 광고 재고·지역별 동의·기기 설정·네트워크 상태에 따라 광고가 표시되지 않을 수 있으며 모든 기기에 광고 표시를 보장하지 않습니다.

알림 해제와 권한 끄기

  • 특정 서버 알림 해제: 해당 통화의 알림 설정에서 ‘급등/급락 알림 해제’를 선택하고 해제 완료 안내를 확인합니다. 서버와 연결되지 않으면 해제가 완료되지 않을 수 있습니다.
  • 모든 알림 표시 중지: iPhone 설정에서 이 앱의 알림 허용을 끕니다. 화면 표시 권한을 끄는 것과 서버 구독 삭제는 다릅니다.
  • 앱 삭제·저장소 초기화: 기기 저장값과 설치 인증 정보가 사라질 수 있습니다. 서버 구독·기기 기록의 즉시 삭제를 보장하지 않으며, 초기화 후 이전 구독을 앱에서 관리하지 못할 수 있습니다.

알림이나 시세가 예상과 달라요

선택 통화·표시 단위·분봉 시각과 최근5분변화, 서버 저장 상태와 iPhone 알림 권한을 확인하세요. 현재1.0.0의 일별 표시값은 분봉 알림의 비교값과 다릅니다. 앱의 참고값은 은행 거래 가격과 다르며 즉시 수신을 보장하지 않습니다.

환율을 공유하거나 복사하려면

환율 홈이나 알림 화면에서 ‘환율 공유’ 또는 ‘내용 복사’를 누릅니다. 선택 통화, 표시 단위, 자료 기준일과 공유한 시각(KST), 앱 안내 링크가 함께 전달됩니다. 일별 자료에는 시세 시각이 없어 공유 시각과 구분합니다. TestFlight 1.0.1(빌드 12)의 분봉 공유에는 분봉 시작·마감 시각(KST), 최근5분변화, 출처와 공유 시각을 구분하여 본문과 앱 안내 링크로 전달합니다. 오래되거나 누락된 분봉을 현재 시세로 안내하지 않습니다. 지난 기준일이면 오늘 시세가 아니라는 안내가 표시됩니다.

공유 링크는 당시 앱에 표시한 자료의 스냅샷이며 새 시세를 자동 조회하지 않습니다. 링크 미리보기는 시세 숫자가 없는 앱 소개 이미지입니다. 수신 앱의 기능·캐시·설정에 따라 미리보기 표시가 달라질 수 있습니다.

현재 알림 기준 · 최근 5분 5원

  • 달러·유로는 1통화, 엔은 100엔 기준입니다. 완료된 최신 1분봉과 정확히 5분 전 봉을 비교하여 5원 이상 상승·하락하면 평가합니다. 연속된 6개 봉이 필요하며 1분마다 수집을 시도합니다.
  • 5원 내려가는 데 5분보다 오래 걸렸다면 최근 5분의 변화는 5원 미만일 수 있어 알림이 발생하지 않을 수 있습니다. 이전 알림부터의 누적 변동이나 매번 본 가격과의 차이를 비교하는 방식은 아닙니다.
  • 분봉 시작 시각 기준 180초를 넘긴 자료, 누락된 봉이나 비정상적인 급변 자료로 알림을 만들지 않습니다. 처음 켜거나 자료 수집이 끊긴 뒤 복구하면 첫 관측은 기준점으로만 저장하고 과거 변동을 뒤늦게 발송하지 않습니다.
  • 같은 방향의 지속 변동은 한 번의 구간으로 처리합니다. 5분 변동폭이 3.5원 미만으로 줄어야 그 구간이 해제됩니다. 같은 통화 구독은 마지막 알림 후 30분 간격과 한국 시간 하루 3회 한도가 적용됩니다.
  • 분봉·수집·전송 지연과 PC·네트워크·기기 설정으로 수신이 늦거나 실패할 수 있습니다. 거래 가격이나 은행 환전 가격을 제공하거나 보장하지 않습니다.

TestFlight 1.0.1(빌드 12)의 광고 개인정보 보완

1.0.1은 모든 광고를 비맞춤 요청으로 유지하며 Google 광고 SDK의 개인화 설정을 차단하고 게시자 자사 광고 식별자를 비활성화합니다. 광고 동의 설정을 열면 실제 SDK 설정 조회 결과를 확인할 수 있습니다. 이 항목은 현재 App Store 1.0.0의 모든 동작이 같다는 뜻이나 실물 기기 검증 완료 안내가 아닙니다.

추적 거절·제한 선택은 유지됩니다. 지역별 Google 개인정보 창은 광고 제공·측정 및 기기 저장 등의 별도 선택이며 여기서 동의해도 iOS 추적 거절이 허용으로 바뀌지 않습니다. Google 창의 필수 목적·파트너 설명과 거절·관리 선택을 확인해 주세요. 비맞춤 광고가 모든 광고 사업자의 쿠키·식별자·측정 처리를 없앤다는 뜻은 아닙니다. 이 앱 자체의 추적 쿠키 동의 배너는 사용하지 않습니다.

광고는 앱이 활성 상태이고 추적 선택을 마쳤으며 UMP 상태가 광고 요청을 허용할 때만 요청합니다. 기본 기능과 기존 알림 조회·해제는 무료입니다. 새 알림 신청은 실제 SDK 보상 완료·광고 종료 확인과 통화별 완료 내역의 기기 저장·읽기 확인 뒤 알림 권한·기기 수신 확인·일치하는 서버 구독 저장을 거칩니다. 같은 통화의 저장 실패 재시도에는 광고를 다시 요구하지 않습니다.
