새 일별 기준환율 버전을 준비하고 있어요

2026년10월7일 PC 알림 서버를 ECB 일별 자료로 전환하고 공개 API와 기존 기기 인증 상태 보존을 확인했습니다. 기존 분 단위 내부 TestFlight 버전은 새 설정에서 알림 신청이 제한됩니다. 대응 네이티브 버전과 실제 iPhone 수신 검증은 아직 완료하지 않았습니다. 일반 App Store 출시는 아직 준비 중입니다.

회원가입·앱 내 구매·자체 분석 SDK는 없습니다. 현재 내부 TestFlight에는 Google 테스트 광고가 있으며 운영 버전의 배너·선택형 보상 광고를 준비합니다.

공표일과 환산 기준을 확인하세요

ECB는 통상 유럽 영업일 약16시(CET)에 참고 환율을 공표하며 TARGET 휴일에는 새 자료가 없을 수 있습니다. 같은 공표일의 EUR/KRW와 EUR/통화 자료를 나누어 원화 참고값을 계산합니다. 시장 거래 시각은 제공하지 않으며 은행 환전·송금 가격·수수료와 다릅니다. 서버는 자료 갱신을 시도하고 실패하면 마지막 공표일 자료를 유지합니다.

출처는 ECB로 고정하며 Frankfurter의 ECB 전용 API 또는 공식 ECB XML을 사용합니다. ECB 미제공 VND·TWD는 제외합니다. 원자료는 무료이며 원화 환산·변동액은 앱의 파생 계산입니다. ECB 무료 원자료 · ECB 이용 조건

추가 콘텐츠 이용

준비 중인 새 버전에서는 추가 카드·번호 세트도 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼을 선택해도 같은 콘텐츠가 제공되며, 그 광고 경로는 실제 SDK 완료 확인 후에만 저장합니다. 광고 취소·실패를 완료로 취급하지 않으며 무료 생성 경로는 계속 이용할 수 있습니다.
