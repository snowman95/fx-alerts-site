새 일별 기준환율 버전을 준비하고 있어요

ECB 일별 자료에 대응하는 내부 TestFlight 1.0.0(빌드 6)을 배포했습니다. TestFlight에서 최신 버전으로 업데이트해 주세요. PC 알림 서버와 공개 API는 ECB 일별 자료를 사용합니다. 실제 iPhone의 알림 수신은 아직 검증 중이며 서버 저장 완료가 실제 수신을 보장하지 않습니다. 일반 App Store 공개 출시는 준비 중입니다.

회원가입·앱 내 구매·자체 분석 SDK는 없습니다. 광고가 포함된 버전은 추적 권한과 광고 개인정보 선택이 모두 광고 요청을 허용할 때 배너·선택형 보상 광고를 제공합니다. 추적을 허용하지 않아도 기본 기능과 같은 추가 콘텐츠를 무료로 이용할 수 있습니다.

공표일과 환산 기준을 확인하세요

ECB는 통상 유럽 영업일 약16시(CET)에 참고 환율을 공표하며 TARGET 휴일에는 새 자료가 없을 수 있습니다. 같은 공표일의 EUR/KRW와 EUR/통화 자료를 나누어 원화 참고값을 계산합니다. 시장 거래 시각은 제공하지 않으며 은행 환전·송금 가격·수수료와 다릅니다. 서버는 자료 갱신을 시도하고 실패하면 마지막 공표일 자료를 유지합니다.

출처는 ECB로 고정하며 Frankfurter의 ECB 전용 API 또는 공식 ECB XML을 사용합니다. ECB 미제공 VND·TWD는 제외합니다. 원자료는 무료이며 원화 환산·변동액은 앱의 파생 계산입니다. ECB 무료 원자료 · ECB 이용 조건

사용 방법과 고객 지원

추가 콘텐츠 이용

추가 비교 카드는 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼을 선택해도 같은 콘텐츠가 제공되며, 그 광고 경로는 실제 SDK 완료 확인 후에만 저장합니다. 광고 취소·실패를 완료로 취급하지 않으며 무료 생성 경로는 계속 이용할 수 있습니다.
